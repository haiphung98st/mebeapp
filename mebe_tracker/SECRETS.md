# Secrets setup

These files are gitignored and required to build the app locally. None of
them are committed — regenerate or copy them per the instructions below.

## 1. `lib/firebase_options.dart`

Auto-generated by the FlutterFire CLI. Regenerate with:

```
dart pub global activate flutterfire_cli
flutterfire configure --project=mebe-tracker
```

This also downloads `ios/Runner/GoogleService-Info.plist` and
`android/app/google-services.json` for you (see below).

## 2. `ios/Runner/GoogleService-Info.plist` / `android/app/google-services.json`

Downloaded automatically by `flutterfire configure` above, or manually from
Firebase Console → Project settings → Your apps → download the config file
for each platform.

## 3. `lib/core/config/app_secrets.dart`

Hand-written, not covered by FlutterFire. Copy the template and fill in
real values:

```
cp lib/core/config/app_secrets.example.dart lib/core/config/app_secrets.dart
```

Currently holds:
- `webGoogleClientId` — Firebase Console → Authentication → Sign-in method →
  Google → Web SDK configuration → Web client ID.

## Server-side secrets (Cloud Functions)

Not stored in any file — managed via Firebase Secret Manager:

```
firebase functions:secrets:set ANTHROPIC_API_KEY --project mebe-tracker
```
